## Node.JS Bootcamp

This bootcamp covers node.js topics from basics to advance

## Topics covered
#### 1.Node module system :
- exports and imports

#### 2.Node-Package-Manager :
- path
- fs
- http
- EventEmitter 

#### 3.Express
- create server
- router
- middleware
- input validation (zod)
- jwt

#### 4.Bookstore-fileserver
- bookstore application which uses fs module of node to save the data

#### 5.Bookstore-mongoerver
- bookstore application which uses mongodb as the database
